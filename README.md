### Тестовое задание
Нужно разработать Python-скрипт, который принимает в качестве аргумента имя пакета приложения на Android. Необходимо запустить указанное приложение на подключенном через ADB телефоне, найти зеленую кнопку в нем (без автоматизаторов типа Appium и т. д.) и нажать на нее. Если кнопка не представлена, вывести сообщение об этом. Таймаут — 10 секунд.

### Реализация 
- Поиск зеленых областей через OpenCV
- Поиск кликабельных элементов через uiautomator
- Сопостовление найденных областей и элементов
- Клик!

Тестировал на нескольких приложениях:
- WhatsApp (com.whatsapp) - работает
- F-Droid (org.fdroid.fdroid) - работает
- WeChat (com.tencent.mm) - не работает, uiautomator возвращает пустоту
- KeePassDX (com.kunzisoft.keepass.free) - не работает
